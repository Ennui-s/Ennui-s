#### 🔥 SmartFire Wild
An environmental monitoring system combining **sensor data and computer vision** to identify wildfire-risk conditions and raise alerts, with the goal of reducing reliance on continuously running expensive low-latency video recognition.

**Focus:** `Computer Vision` · `Sensor Data` · `Machine Learning` · `AI Systems`

#### 💳 Multimodal Financial AI Agent
A multimodal application using **vision-language models** to interpret handwritten financial documents, convert the information into structured data, and use it to provide affordability and planning recommendations.

**Focus:** `VLMs` · `Multimodal AI` · `Structured Data` · `AI Applications`

A transfer-learning image classification system trained on a custom dataset, using checkpointing and early stopping. The final model achieved approximately **95.2% test accuracy**, with confusion-matrix and Grad-CAM analysis used to examine model behaviour.

**Focus:** `PyTorch` · `Computer Vision` · `Transfer Learning` · `Model Evaluation`

A Japanese manga translation project designed to identify text regions and Japanese characters within manga, interpret the surrounding context, and translate the content into English while considering **personality, situation and tone**.

**Focus:** `Computer Vision` · `OCR` · `NLP` · `Multimodal AI`

A learning-management dashboard incorporating an AI model to identify students who may be struggling, alongside the surrounding interface and application features.

**Focus:** `AI Applications` · `Data` · `Frontend` · `Education Technology`

A Japanese manga translation pipeline that identifies text regions and in-image hiragana/katakana,

Financial Multimodal AI Agent (AI, CV, API, LLM, Agentic, Decision)

A multimodal financial assistant that uses vision-language models such as Claude, Gemini and

Plant Disease Classification (AI/ML, CV, CNN)

A transfer-learning image-classification system trained on a custom 224×224 plant-image dataset,
using checkpointing and early stopping to identify plant diseases; the model achieved 95.18% test
accuracy, with confusion matrices and Grad-CAM used to evaluate its predictions and visual
attention.

  
Smart LMS Dashboard (AI/ML, Playwright, RNN, Decision)

A learning-management dashboard that combines a lecturer-facing interface with an AI model

through the system rather than relying solely on manual monitoring.
